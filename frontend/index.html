FT-950 AUDIO MENUS (EX)
—

Values are set in the FT-950 via CAT and read back. Default = the known-good state of the station (saved on the first read). Differences are marked, ↺ resets a single menu. Note: 051 is the only control for the RX level to the Pi (the codec has none), 050 is the modulation in DATA-U.

VOICE TX PROCESSING

Applied to the microphone on transmit (and in MIC TEST, so you can listen to the result). A limiter at the end keeps peaks below full scale.

WEBRTC BUFFERS

TX BUFFER: upper limit of the microphone backlog — smaller = less delay, larger = more robust against network jitter (recommended 150 ms). Playback starts only at half the buffer size (max. 60 ms) so it does not sound choppy. TX TRAIL: hang time after release so the end is not cut off (recommended 250 ms). RX BUFFER: buffer between the codec clock and the WebRTC clock — raise it if receive audio crackles, lower it for the shortest delay (recommended 60 ms).

051 and 050 are set in the radio via CAT and read back. For FT8, set the RX level so the bar sits in the green range; peaks above −1 dBFS light OVL.

Changes apply immediately

Wavelog creates the API token under Account → API Keys (read/write). It stays on the Pi only (runtime.json, readable by root only) and is never sent back to the browser — an empty field keeps the saved value.

QRZ.COM
not tested

Username + password: callsign lookup (name, locator, QTH) via the QRZ XML service — requires a QRZ XML subscription. Logbook API key (QRZ.com → My Logbook → Settings): every QSO is additionally uploaded to the QRZ logbook.

AUTOMATION

Worked-before check as in iDigi: CQ red = station already in the log on this band, green = new; NEW = DXCC entity never worked. The index is reloaded from Wavelog at start-up and every 10 minutes. Auto-log kicks in as soon as the auto-sequencer completes QSOs.

—

Frequency and mode are written into the radio's memory channel (MW) and checked by reading it back. CTCSS (mode and tone) is stored in the radio too and set on recall in FM; clarifier and shift of an existing channel are kept. The FT-950's memories have no split and no VFO B, and it cannot name or clear a memory over CAT — so split, VFO B and the name are stored here on the Pi and applied on recall (VFO B gets A's mode, then its own frequency; split sets TX on B, a key without split sets TX on A).
